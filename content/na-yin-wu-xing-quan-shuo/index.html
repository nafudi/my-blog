纳音五行全说

计算 · 口诀 · 解析 · 合冲 · 深层原理

纳音五行是命理学中最重要的概念体系之一。六十甲子分为三十组，每组共享一种纳音五行。 本篇从太玄数计算规则出发，经过记忆口诀和三十象解析，延伸到天干合与地支冲的数理本质， 最后深入探讨纳音的两大核心疑问——为什么必须"双体"计算？为什么公式只能定五行而不能定物象？

一、太玄数与计算规则

纳音五行的归属并非随意命名，而是有一套严密的数理公式。该方法源于汉代扬雄的《太玄经》， 通过为天干地支赋值，即可快速推算任意干支组合的纳音五行。

核心公式

纳音五行 = （天干₁ + 地支₁ + 天干₂ + 地支₂）÷ 5 的余数
余数对照：余 1 → 火 ｜ 余 2 → 土 ｜ 余 3 → 木 ｜ 余 4 → 金 ｜ 余 0 → 水

验证举例

  • 甲子乙丑：9+9+8+8 = 34，34÷5 余 4 → 金（海中金）金
  • 丙寅丁卯：7+7+6+6 = 26，26÷5 余 1 → 火（炉中火）火
  • 戊辰己巳：5+5+9+4 = 23，23÷5 余 3 → 木（大林木）木
  • 庚午辛未：8+9+7+8 = 32，32÷5 余 2 → 土（路旁土）土
  • 壬申癸酉：6+7+5+6 = 24，24÷5 余 4 → 金（剑锋金）金
  • 甲戌乙亥：9+5+8+4 = 26，26÷5 余 1 → 火（山头火）火
  • 丙子丁丑：7+9+6+8 = 30，30÷5 余 0 → 水（涧下水）水
  • 戊寅己卯：5+7+9+6 = 27，27÷5 余 2 → 土（城头土）土
  • 庚辰辛巳：8+5+7+4 = 24，24÷5 余 4 → 金（白蜡金）金
  • 壬午癸未：6+9+5+8 = 28，28÷5 余 3 → 木（杨柳木）木

以此类推，所有六十甲子均符合此规律。

三、三十象解析

纳音五行的命名源于十二长生与五行生克关系。每组天干地支所处的长生阶段（生、旺、死、墓、绝等） 决定了该纳音的性质与意象。以下逐一解析三十种纳音的原文含义。

金（六种）

1. 海中金 — 甲子、乙丑

甲子乙丑海中金者，子属水，又为湖，又为水旺之地，兼金死于子，墓于丑，水旺而金死墓，故曰海中金也。
子是水旺之地，金在子死、在丑墓。金死墓于水旺之地，如同沉在大海，故称海中金。

2. 金箔金 — 壬寅、癸卯

壬寅癸卯金箔金者，寅卯为木旺之地，木旺则金缺，金绝于寅，胎于卯，金既无力，故曰金箔金也。
金在寅卯处绝地、胎地，极其微弱，且被旺木所缺，薄如蝉翼，故称金箔金。

3. 白蜡金 — 庚辰、辛巳

庚辰辛巳白蜡金者，金养于辰，生于巳，形质初成，未能坚利，故曰白蜡金也。
金在辰为养地，在巳为生地，刚刚成形，质地柔软不坚，如白蜡一般，故称白蜡金。

4. 沙中金 — 甲午、乙未

甲午乙未沙中金者，午为火旺之地，火旺则金败，未为火衰之地，火衰则金冠带。败而冠带，未能斫削，故曰沙中金也。
金在午败（死），在未冠带。此时金混在火生土的沙石中，需要淘洗才能得金，故称沙中金。

5. 剑锋金 — 壬申、癸酉

壬申癸酉剑锋金者，金临官于申，帝旺于酉，金既生旺，则成刚矣，故曰剑锋金也。
申酉是金最旺盛的时候，刚强锋利，如同宝剑之锋，故称剑锋金。

6. 钗钏金 — 庚戌、辛亥

庚戌辛亥钗钏金者，金至戌而衰，至亥而病，金既衰病，则诚柔弱，故曰钗钏金也。
金在戌亥处衰病之地，气势已尽，变得柔弱，只能做成首饰钗钏，故称钗钏金。

木（六种）

1. 杨柳木 — 壬午、癸未

壬午癸未杨柳木者，木死于午，墓于未。甲乙木至午则死，至未则墓。木既死墓，虽得天干壬癸之水以生之，终是柔弱，故曰杨柳木也。
木在午死、在未墓。虽有壬癸水生养，但根基已失，如同杨柳随风摇摆，柔弱无力。

2. 松柏木 — 庚寅、辛卯

庚寅辛卯松柏木者，木临官在寅，帝旺在卯，木既生旺，则非柔弱之比，故曰松柏木也。
木在寅卯处于最旺盛的临官、帝旺之地，质地坚硬，如同松柏经冬不凋，故称松柏木。

3. 平地木 — 戊戌、己亥

戊戌己亥平地木者，戌为原野，亥为木生之地，盖木生亥，而死在午，墓在未，今以此戌亥为平地，故曰平地木也。
戌为平原旷野，亥是木生之地，木生于平原，故称平地木。

4. 桑柘木 — 壬子、癸丑

壬子癸丑桑柘木者，子属水，丑属金，金生水，水生木，其气发越，故曰桑柘木也。
水旺生木，但处于寒冬，桑柘之木耐寒，且其叶可饲蚕，多用于实务，非参天大树。

5. 石榴木 — 庚申、辛酉

庚申辛酉石榴木者，申为七月，酉为八月，此时木气已绝，惟石榴之木结实，故曰石榴木也。
申酉是金旺木死之地，万木凋零，唯独石榴树在这个时候结实，故称石榴木。

6. 大林木 — 戊辰、己巳

戊辰己巳大林木者，辰为原野，巳为六阳，木至六阳则枝荣叶茂，以茂盛之木而在原野之间，故曰大林木也。
辰是水库湿土，巳是温暖之地，木气繁茂，生于原野，故称大林木。

水（六种）

1. 涧下水 — 丙子、丁丑

丙子丁丑涧下水者，水旺于子，衰于丑，旺而反衰，则不能为江河，故曰涧下水也。
水在子旺，在丑衰。旺水遇衰地，不能形成大江大河，只能流于山涧，故称涧下水。

2. 井泉水 — 甲申、乙酉

甲申乙酉井泉水者，金生水，水生木，申酉金之旺地，木死于申，墓于酉，水源不断，而木不能受，故曰井泉水也。
申酉金旺生水，水源源不断，但木死墓无法吸纳水，水积聚一处而不流动，如井中之泉。

3. 长流水 — 壬辰、癸巳

壬辰癸巳长流水者，辰为水库，巳为金长生之地，金生水，水性不绝，故曰长流水也。
辰是水库，巳中金生水，水源不断，细水长流，故称长流水。

4. 天河水 — 丙午、丁未

丙午丁未天河水者，丙丁属火，午为火旺之地，火旺则水气为火所化，其水在天，故曰天河水也。
午是火旺之地，水在火旺处被蒸发上天，化为雨露，故称天河水。

5. 大溪水 — 甲寅、乙卯

甲寅乙卯大溪水者，寅为东北，卯为正东，水流正东，则其性顺，川涧俱纳，故曰大溪水也。
寅卯是木旺之地，水生木，水被泄气但流向东方，汇聚成溪流，故称大溪水。

6. 大海水 — 壬戌、癸亥

壬戌癸亥大海水者，水冠带在戌，临官在亥，水冠带临官，则其源远流长，故曰大海水也。
亥是水临官旺地，戌是冠带，水势浩大，百川归海，故称大海水。

火（六种）

1. 炉中火 — 丙寅、丁卯

丙寅丁卯炉中火者，寅为三阳，卯为四阳，火既得地，又得木生，此火气方生，故曰炉中火也。
寅卯属木，木生火，火在地支中有根，如同在炉灶中燃烧，故称炉中火。

2. 山头火 — 甲戌、乙亥

甲戌乙亥山头火者，戌亥为天门，火照天门，其光在上，故曰山头火也。
戌亥为天门，火在此位高高在上，如同山头的野火或晚霞，故称山头火。

3. 霹雳火 — 戊子、己丑

戊子己丑霹雳火者，子属水，丑属土，水中之火，水火相激，则声如雷，故曰霹雳火也。
子是水，火在水中，水火相激，如同雷电霹雳，故称霹雳火。

4. 山下火 — 丙申、丁酉

丙申丁酉山下火者，申为地户，酉为日落之所，日藏于山，故曰山下火也。
申酉是日落西山的时候，太阳隐没在山下，余辉闪烁，故称山下火。

5. 覆灯火 — 甲辰、乙巳

甲辰乙巳覆灯火者，辰为食时，巳为日中，日中则昃，光不显，故曰覆灯火也。
辰巳是白天，太阳升起，灯火的光芒被掩盖，故称覆灯火。

6. 天上火 — 戊午、己未

戊午己未天上火者，午为火旺之地，未为木库，木生火，火势炎上，故曰天上火也。
午是火最旺之地，火势极盛，烈日当空，故称天上火。

土（六种）

1. 路旁土 — 庚午、辛未

庚午辛未路旁土者，未为土，午为火，火生土，其气已发，故曰路旁土也。
火生土，土气生发，但此时土是生发之始，田地之土，也就是路边之土，故称路旁土。

2. 城头土 — 戊寅、己卯

戊寅己卯城头土者，寅卯木旺之地，土为木所制，其势不能远及，故曰城头土也。
寅卯木旺克土，土被木控制，不能延伸，只能堆积如城墙，故称城头土。

3. 屋上土 — 丙戌、丁亥

丙戌丁亥屋上土者，戌亥为天门，土居天门，高处立基，故曰屋上土也。
戌亥是天门，位置极高，土在高处，如同房屋的瓦土，故称屋上土。

4. 壁上土 — 庚子、辛丑

庚子辛丑壁上土者，丑为土，子为水，水和土而泥，故曰壁上土也。
子是水，丑是土，水土能和成泥，用于涂墙，故称壁上土。

5. 大驿土 — 戊申、己酉

戊申己酉大驿土者，申为坤，坤为地，酉为兑，兑为泽，泽与地连，故曰大驿土也。
申为地，酉为泽，通衢大道，四通八达，故称大驿土。

6. 沙中土 — 丙辰、丁巳

丙辰丁巳沙中土者，辰为水库，巳为金生，土之有水有金，而无力，故曰沙中土也。
辰是水库，巳是金生地，土中混杂了水和金，变得松散不实，故称沙中土。

四、天干合与地支冲的数理本质

在太玄数体系中，一个有趣的现象是：天干数值相同为"合"，地支数值相同却为"冲"。 同样的数字，为什么在天干和地支中表现出截然相反的关系？答案藏在中国哲学最核心的"体用"逻辑中。

天干同数：为何是"合"？

天干代表天道、气、功能。古人认为，同气相求，性质相同（数值相同）的事物，在天道层面会相互感应、融合。

数理上的"中正"

以甲己合化土为例：甲数9，己数9。在洛书九宫中，5是中央土的数字。甲(9) + 己(9) = 18，1+8 = 9。甲己之中数为5（土之生数），与中央土相应。

阴阳互补

天干有阴阳之分。甲是阳木，己是阴土，虽然数值都是9，但一个是阳，一个是阴。孤阴不生，独阳不长。当两个数值相同但阴阳属性相反的天干相遇时，就像正负电荷吸引一样，会发生强烈的"化学反应"。这种吸引力叫"合"。合，意味着和谐、协作、生成新事物。

结论：天干数值相同，代表它们在同一能量等级上。阴阳相配，势均力敌，故能合。

地支同数：为何是"冲"？

地支代表地道、质、方位。地支是有实体的、有方位的。在同一个圆周上，力量相等意味着位置对立。

方位上的"对冲"

子（9）与午（9）：子是正北（水），午是正南（火），在圆周上正好相差180度。卯（6）与酉（6）：卯是正东（木），酉是正西（金）。就像两个人拔河，力气完全一样大（数值相同），方向相反，形成最剧烈的对抗。

五行相克

六组相冲的地支，虽然数值相同，但五行往往是相克的：

子（水）冲午（火）——水克火
寅（木）冲申（金）——金克木
卯（木）冲酉（金）——金克木

势均力敌 + 性质相反 = 最激烈的冲突。

结论：地支数值相同，代表它们在空间上处于对立面，能量相当且互不相让，故为冲。

体用对照：天圆地方

比较维度天干（天道）地支（地道）
性质气（流动的、虚无的）质（实体的、方位的）
同数含义同频共振（如两个音叉共鸣）能量对等（如两球对撞）
相遇结果合（融合为一体）冲（撞击并损伤）
哲学解释天主动，动则相吸，追求统一地主静，静则对峙，追求分明

一个形象的比喻

想象"9"这个数值：

在天干（甲、己）：就像两个才华相当的人（都是9分能力），一个男（阳），一个女（阴）。他们因为能力匹配、三观一致（数值相同），所以结为夫妻——这就是"甲己合"。

在地支（子、午）：就像两个武林高手（都是9分武功），一个在山南（午火），一个在山北（子水）。他们功力相当，但立场完全相反。一旦相遇，必然拼个你死我活——这就是"子午冲"。

同数相合（天干）：阴阳调和，精神层面的共鸣

同数相冲（地支）：势均力敌，物质层面的对抗

古人的数字模型并非乱排，而是将物理法则（力的相互作用）和伦理法则（阴阳和合）完美融入了这十个数字之中。

五、为什么单看"甲子"算不出来？

因为纳音五行原本就是"双体共振"的产物，而非单体属性。

在六十甲子纳音中，五行属性是每两个干支共享的（甲子、乙丑同属金；丙寅、丁卯同属火……）。古人为什么这样设计？

从音律角度（纳音的本源）

纳音脱胎于古代乐律学（十二律吕）。在乐律中，单音不成乐，必须阴阳相配（如黄钟配林钟）。 甲为阳，子为阳；乙为阴，丑为阴。甲子与乙丑，是一阳一阴的共振，产生一个特定的"音" （即五行属性）。所以，必须把两个干支的太玄数加在一起，才构成一个完整的频率/音律。

从气数角度

如果只算"甲子"，甲9+子9=18，18÷5余3，按公式余3为"木"。但甲本就是阳木， 子中藏癸水，这叫"本气"，而纳音算的是"化气"（两者结合后产生的新物质）。 单独的甲子只是原材料，甲子加上乙丑，才完成了从"原料"到"新物质"的化学反应。

结论：太玄数求纳音五行，必须把一对干支（四个字）的数全加起来， 这反映的是"耦合"后的结果，而不是单个干支的先天属性。

六、为什么算不出"海中金"，只能算出"金"？

因为你推导的这个公式（总和÷5看余数），它的功能上限就是"定五行"，而定不了"纳音象"。

完整的纳音包含两部分：五行（体）+ 物象（用）。

五行（金木水火土）：是定性的，由数学规律（如你总结的除以5看余数）严格推导。
物象（海中、炉中、大林木等）：是定象的，是古人对这组五行在不同阶段（十二长生宫）的意象描述，无法用简单的除法得出。

"海中金"的"海中"是怎么来的？

它是基于五行十二长生的逻辑：

甲子、乙丑的五行是"金"（你的公式已证明）。
金的长生在"巳"，帝旺在"酉"，墓库在"丑"。

看"甲子"：子在十二地支中，对于金来说，处于"死"地（水泄金气，金沉水底）。
看"乙丑"：丑是金的"墓库"（金气隐藏收藏）。

甲子金在"死"地（水底），乙丑金在"墓"地（埋藏），两者都是金气极其微弱、深藏不露、被水/土掩埋的状态。 古人看到这种"金沉水底、暗藏于下"的易象，就给它取了一个形象的名字——海中金。

同为金，不同象的对比

壬寅、癸卯 — 金箔金

金处于"绝"地，但寅卯属木，金藏在木中，如同刀剑未开刃，薄如蝉翼。

庚辰、辛巳 — 白蜡金

金处于"长生/养"地，刚刚萌发，夹杂在矿石泥土中，质地柔软。

甲午、乙未 — 沙中金

金处于"沐浴/冠带"之地，经过火炼，开始成型，混在沙石中。

壬申、癸酉 — 剑锋金

金处于"帝旺/临官"之地，金气最盛，坚刚无比，锋利如剑。

总结：太玄数公式（÷5取余）解决的是"是什么五行"的问题， 而"海中""剑锋""白蜡"这些物象名称，需要结合十二长生宫（死、墓、绝、养、旺等） 才能确定。两者缺一不可，合在一起才是完整的纳音。
